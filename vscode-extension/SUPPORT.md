# Support

## Before opening an issue

1. Confirm that the workspace contains `.tapl/tapl.db`.
2. Run `tapl-mcp` from a terminal and confirm that the command is available.
3. If the command is installed outside `PATH`, set
   `taplWorkflow.taplMcpPath` to its absolute path.
4. Run **Developer: Show Running Extensions** and confirm that TAPL Workflow
   Viewer is active for the workspace.
5. Run **TAPL Workflow: Refresh Workflow Views** after restarting VS Code.

## Report a problem

Use [GitHub Issues](https://github.com/qkdxorjs1002/tapl/issues) and include:

- the extension and VS Code versions;
- your operating system;
- the `tapl-mcp` installation method and path;
- exact reproduction steps;
- relevant output with secrets and private workspace data removed.

For a security vulnerability, use
[GitHub private vulnerability reporting](https://github.com/qkdxorjs1002/tapl/security/advisories/new)
instead of a public issue.
